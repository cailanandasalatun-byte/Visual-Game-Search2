# TicTacToe
  Permainan papan yang dimainkan oleh dua pemain Tic Tac Toe adalah permainan papan yang dimainkan oleh dua pemain, di mana satu pemain menggunakan simbol "X" dan yang lainnya menggunakan simbol "O". Tujuan permainan adalah untuk menjadi pemenang dengan membuat tiga simbol berturut-turut secara horizontal, vertikal, atau diagonal.
